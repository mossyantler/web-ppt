유의미한 공백 보존

아래 pre 세 개의 공백은 내용이다. 재들여쓰기하면 의미가 깨진다.

첫 줄: 이 줄 앞 개행은 파서가 버리지만 소스 바이트에는 남아 있다.
    스페이스 4개 들여쓰기
	탭 1개 들여쓰기
        스페이스 8개 들여쓰기
  혼합	탭과 스페이스가 한 줄 안에 섞임
줄 끝에 스페이스 3개가 있다
여는 태그와 내용이 같은 줄인 pre
def solve(x):
    if x > 0:
        return x ** 2
    return 0
